# prompts/ — 提示词资产库

> 执行计划书 §8 代码质量红线:**提示词一律进本目录,不硬编码进代码**。
> 后端各功能按文件名加载;AI 写码时本目录与 `可用\` 同为合法上下文。

## 目录约定

```
prompts\
├── README.md            本文件
├── 系统级\              (预留)装配协议/检查协议等系统提示词
├── 技能\                (预留)审稿对话台可挂载技能(M5)
└── 旧系统平移\          从旧系统原样平移的资产,内容不改,只加出处头
```

> 注:混沌/初绽两份平移件当前直接置于根目录(M0 提取件),M4 接入审稿对话台时归位到对应子目录。

## 命名规则

- `<用途>-<内容>.md`,如 `审稿-story-review维度.md`;
- 旧系统平移件保留原名:`<原助手名>-提示词.md`;
- 每份文件头部必须有出处块(从哪来、何时提取、是否做过剥离处理)。

## 安全纪律

- 任何提示词入库前正则核对 API key 形态(脚本 `scripts/extract_prompts.py` 的 KEY_PATTERNS);
- key 本体只存在 `data/secrets.local.json`(git 忽略)或用户设置页,永不进本目录。
