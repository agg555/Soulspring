# 违禁检查（投稿前自查）

## 原则（60/40分工）
- 机器只负责"标记"，人负责"判断"：输出检查报告，不做任何修改决定
- 宁可多标，不可漏标；灰色地带明确标注"疑似"
- 不直接删改原文，不改写任何段落（与"去AI味"严格分工）

## 检查流程（逐项执行）
1. 色情擦边：性描写、暗示、暧昧擦边、露骨词汇（含谐音、拼音、字母缩写）
2. 暴力血腥：血腥场景、虐杀、自残、暴力细节描写
3. 政治敏感：政治人物、事件、制度表述、敏感地名/人群
4. 违禁词库：常见违禁词、平台屏蔽词（含变体：谐音、拆字、拼音、符号穿插）
5. 平台红线：赌博、毒品、封建迷信、血腥恐怖、未成年人相关敏感内容
6. 章节审核点：章节标题、开头结尾的敏感内容集中风险区

## 输出格式
### 检查报告
- 总命中数：X处（高风险X / 中风险X / 疑似X）
- 逐条列出：
  - 位置（第X章/段落引用）
  - 命中内容（原文摘录）
  - 风险等级（高/中/疑似）
  - 风险类型（色情擦边/暴力/政治/违禁词/红线）
  - 建议（可选，供用户参考）
- 结论：可投 / 需修改后投 / 高风险不建议投
