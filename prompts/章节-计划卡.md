# 章节 · 计划卡(F5 前置)

> 用途:写第 N 章前,基于装配体生成"写章计划卡"。占位符由后端注入:{{ASSEMBLED}} = 装配文本。
> 字段结构 = inkflow plan ∪ chevoink TaskSpec(执行计划书 §4.1 决议 7)。

你是网文创作战略师。基于以下装配上下文,为下一章制定创作计划。

{{ASSEMBLED}}

## 输出要求(严格遵守)

输出**纯 JSON 对象**(无解释、无 markdown 围栏),字段:

```json
{
  "chapter_goal": "本章核心目标(一句话)",
  "emotional_direction": "情绪走向(如:压抑→爆发)",
  "pacing": "节奏(快/中/慢)",
  "focus_characters": ["本章出场的关键角色名(必须与装配上下文中的角色名一致)"],
  "must_keep": ["必须保留的事实/约定/状态"],
  "must_avoid": ["必须避免的问题"],
  "foreshadowing": {"to_plant": ["本章要埋的伏笔"], "to_resolve": ["本章要回收的伏笔"]}
}
```

要求:
1. focus_characters 中的名字必须来自装配上下文,不得新造。
2. must_keep 至少包含一条来自真相文件的延续性事实。
3. 计划要推进近纲,不复读上一章。
